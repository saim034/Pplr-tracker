MY PPLR TRACKER — ANDROID INSTALLABLE WEB APP

This is an installable Progressive Web App (PWA), not a signed APK.
It can be installed on Android from Chrome after it is hosted on an HTTPS website.

HOW TO PUBLISH:
1. Upload the CONTENTS of this folder to a static website host that supports HTTPS
   (for example, GitHub Pages or Netlify).
2. Open the published HTTPS address in Chrome on your Android phone.
3. Open Chrome's menu (⋮) and choose "Install app" or "Add to Home screen".
4. Confirm. The PPLR Tracker icon will appear with your other apps.

OFFLINE:
After opening the app online once, its main files are cached for offline use.
Workout data is stored in the browser on that device. Use Export backup inside
the app regularly. Clearing Chrome site data can erase local workout records.

IMPORTANT:
A direct APK file is not included. Creating a signed APK requires an Android
packaging/signing step. This PWA can be installed without Play Store.
